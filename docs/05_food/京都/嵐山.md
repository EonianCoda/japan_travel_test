# 京都・嵐山美食

---

## 抹茶甜點

### 嵐山OBUU

| 項目 | 說明 |
|------|------|
| 特色 | 嵐山超人氣抹茶甜點店，招牌「抹茶巴巴洛」帶有濃鬱茶香和軟糯口感。另有抹茶霜淇淋、抹茶聖代等選擇。排隊時間常達30分鐘以上，建議一早前往 |
| 價位 | ¥500-1,000 |
| 營業時間 | 10:00-17:00 |
| 地址 | 京都市右京區嵯峨嵐山町 |

### % Arabica

| 項目 | 說明 |
|------|------|
| 特色 | 京都知名咖啡店，咖啡拉花精緻是打卡熱點。店址面向桂川河，濱河位置景觀絕佳。咖啡豆自家烘焙，抹茶拿鐵同樣人氣極高。排隊時間不長，適合計劃悠閒品咖啡賞河景 |
| 價位 | ¥400-700 |
| 營業時間 | 9:00-18:00 |
| 地址 | 京都市右京區嵯峨天龍寺車道町1 |

### ARINCO

| 項目 | 說明 |
|------|------|
| 特色 | 嵐山必喫的抹茶甜點專門店，抹茶霜淇淋茶香濃鬱超人氣。使用宇治抹茶製作，另有抹茶大福、抹茶蛋糕等。排隊名店，建議平日或一大早前往 |
| 價位 | ¥400-800 |
| 營業時間 | 10:00-17:00 |

### 雲ノ茶

| 項目 | 說明 |
|------|------|
| 特色 | 嵐山新店，以「抹茶雲朵吐司」和「抹茶雲朵拿鐵」在IG爆紅。吐司上覆蓋如雲朵般的抹茶鮮奶油，視覺夢幻。排隊人潮眾多，建議平日前往 |
| 價位 | ¥600-1,200 |
| 營業時間 | 10:00-17:00 |

## 湯豆腐

### 三忠豆腐

| 項目 | 說明 |
|------|------|
| 特色 | 嵐山超人氣湯豆腐名店，採用自家製作的湯豆腐和腐皮。豆皮是亮點無論是湯豆腐或腐皮都綿密細膩。店內座位不多，總是大排長龍，建議開店前就去排隊 |
| 價位 | ¥1,500-3,000 |
| 營業時間 | 11:00-16:00 |
| 地址 | 京都市右京區嵯峨天龍寺 |

### 湯豆腐竹村

| 項目 | 說明 |
|------|------|
| 特色 | 嵐山歷史悠久的湯豆腐老店，位於天龍寺附近。湯豆腐質地細膩、豆香濃鬱，搭配特製醬油品嚐。冬季限定的「豆皮鍋」更是招牌。提供網路預約服務 |
| 價位 | ¥1,500-3,500 |
| 營業時間 | 11:00-21:00 |
| 官方連結 | [takumura.co.jp](https://www.takumura.co.jp/) |
