## 燒肉

### 京燒肉弘

| 項目 | 說明 |
|------|------|
| 特色 | 京都知名燒肉連鎖，使用的黑毛和牛皆為自家整頭採購，品質穩定。祇園山名庵分店位於百年歷史町家建築內，洋溢京情。推薦「當日限定牛肉拼盤」可品嚐多種部位，配多樣沾醬口感豐富。招牌「牛大腹炙燒壽司」入口即化，「夏多布里昂」厚切牛肉更是稀有部位。提供中文菜單 |

| 地址 | 京都市中區四條祇園町北側 |
| 官方連結 | [yakinikukou.co.jp](https://www.yakinikukou.co.jp/) |

## 咖啡輕食

## 日式甜點

### Yojiya Cafe

| 項目 | 說明 |
|------|------|
| 特色 | 京都最具代表性的藝妓咖啡，招牌「藝妓臉」拉花抹茶卡布奇諾或抹茶拿鐵是打卡熱點。祇園店限定「抹茶紅豆栗子蛋糕捲」和抹茶聖代也值得一試。店內附設商店販售限定版周邊商品，是京都旅遊伴手禮熱門選擇 |
| 價位 | ¥500-1,200 |
| 營業時間 | 10:00-18:00 |
| 官方連結 | [yojiya.co.jp](https://www.yojiya.co.jp/) |

| 項目 | 說明 |

| 營業時間 | 12:00-18:00 |
