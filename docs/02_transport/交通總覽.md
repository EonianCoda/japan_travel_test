## 🟠 JR Pass 系列

### 關西地區鐵路周遊券 (JR-West Kansai Area Pass)

| 天數 | 成人 | 兒童 | 適用範圍 |
|------|------|------|----------|
| 1日 | ¥2,800 | ¥1,400 | 大阪、京都、奈良、神戶 |
| 2日 | ¥4,200 | ¥2,100 | 同上 |
| 3日 | ¥5,200 | ¥2,600 | 同上 |
| 4日 | ¥6,300 | ¥3,150 | 同上 |

**特色**：
- 可搭乘JR普通列車、快速列車

- 線上購買後至關西機場、兌換

**官方連結**：[JR-West Kansai Area Pass](https://www.westjr.co.jp/travel-information/tc/tickets-passes/jrwest-rail-pass/kansai/)

## 🟡 IC 卡（類似悠遊卡）

### ICOCA

| 項目 | 說明 |
|------|------|
| 押金 | ¥500 |
| 儲值 | 可反覆加值 |
| 退還 | 可在任何JR車站退還，押金不退但可取餘額 |
| 適用 | 關西大部分交通（JR、私鐵、地鐵、巴士） |
| 購買處 | 關西機場、大阪/京都車站JR綠色窗口 |

### SUICA / PASMO

- 關東版SUICA可在關西使用（但不可退卡）
- 建議已有PASMO可繼續使用

## 🚃 嵐山小火車（嵯峨野觀光鐵道）

| 項目 | 說明 |
|------|------|
| 路線 | 龜岡車站⇄嵐山車站（直線約25分） |
| 票價 | 單程約¥800、來回¥1,500 |
| 運行時間 | 9:00-17:30（班次約每30分） |
| 冬季停駛 | 12/1～2/28 定期運休 |
| 預訂 | 賞櫻/賞楓季建議提前一個月預訂 |

**建議**：
- 去程坐右側（景色佳）
- 回程坐左側
- 建議搭配JR嵯峨野線使用

**官方連結**：[嵐山小火車](https://www.sagano-kanko.co.jp/)

## ⚠️ 實用提醒

### 日本連休假（2026年）
- **10/11～10/13**：體育之日（體育の日）附近
- **11/1～11/3**： 文化之日（文化の日）
- **11/22～11/24**： 勤勞感謝之日

> 連休假期間各景點人潮洶湧、交通擁擠，建議避開或提前預約

### 乘車禮儀
- 博愛座請讓給需要的乘客
-電車內避免（大聲說話、使用手機通話
- 跟上車時排隊依序

### 小提醒
- JRpass不涵蓋私鐵（如嵐電、叡山電鐵）
- 請妥善保管JRpass，乘車時需出示
- ICOCA可適用於大部分私鐵，但不可用於嵐山小火車
