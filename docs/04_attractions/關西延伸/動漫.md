# 動漫聖地巡禮

---

## 名偵探柯南（コナン）聖地

| 地點 | 作品場景 | 建議停留 |
|------|----------|----------|
| **清水寺** | 紅色修學旅行篇 - 新蘭世紀之吻、動畫取景 | 2-3小時 |
| **五條大橋** | 柯南與服部平次相遇的地點 | 30分支 |
| **鞍馬寺→鞍馬駅** | 動畫中平次的爆走場景 | 2小時 |
| **通天閣** | 《世紀末的魔術師》怪盜基德宣言場景 | 1.5小時 |
| **大阪環球影城 USJ** | 柯南解謎遊戲設施、4-D表演 | 半天 |
| **梅田藍天大廈** | 《天空的遇難船》空中庭園展望臺 | 1小時 |
