## 🌊 箕面公園・箕面瀑布（大阪）

### 景點特色

箕面公園是關西地區最經典的賞楓祕境之一，從**箕面站**沿著「瀧道」步行約40分鐘即可抵達日本百大瀑布之一的**箕面大瀑布**（落差約13公尺）。

秋季時，整條瀧道被赤紅與金黃的楓葉覆蓋，形成「楓葉隧道」，沿途還有**瀧安寺**（傅馬院棧道）、竹林的自然景觀。

### 秋季活動

- **箕面公園楓葉節**：每年11月在瀑布周邊舉辦
- **箕面大瀑布夜間點燈**：2025年因火災暫停，2026年恢復與否需確認

### 詳細資訊

| 項目 | 說明 |
|------|------|
| 票價 | 免費（瀑布本身免費參觀） |
| 賞楓時期 | 11月中旬～12月上旬 |
| 建議停留 | 2-3小時 |
| 地址 | 箕面市箕面公園 |
| 交通 | 從大阪站出發：JR→石橋阪大前站→換乘阪急箕面線至「箕面站」，步行40分鐘 |

### 推薦路線

```
箕面駅
    ↓（40分鐘沿瀧道步行）
箕面大瀑布
    ↓（可繼續往上）
勝尾寺
```

> ⚠️ 2025年11月瀑布前的遊步道（瀧道）曾發生火災，部分路段可能有限制，出發前請確認現況

### 特產

- **炸楓葉**：箕面地區傳統小喫，用真正的楓葉裹麵衣酥炸，甜甜鹹鹹
- 沿途有小型攤位可購買

## 🌸 嵐山賞楓夜遊（京都）

### 嵐山月燈路（Arashiyama Bamboo Path）

**2025年活動資訊（2026年請確認）**：

| 項目 | 說明 |
|------|------|
| 活動名稱 | 嵐山月燈路（原嵐山花燈路） |
| 舉辦時間 | 每年10月（2025年為10/1-10/31） |
| 舉辦時段 | 18:00-21:00（最終入場20:30） |
| 付費區 | 今年首度設置付費區，竹編燈籠作品為主 |

### 點燈範圍

- **竹林小徑**：藍綠色燈光映照竹林，營造神祕氛圍
- **渡月橋**：夜晚點燈，運河倒影與燈光交織
- **野宮神社**：周邊竹林小徑同步點燈
- **嵐山公園**：日式靜謐燈影

### 嵐山賞楓（10月下旬～12月上旬）

嵐山地區賞楓熱點：

| 景點 | 特色 | 賞楓期 |
|------|------|--------|
| **天龍寺** | 曹源池庭園，借景嵐山與龜山的池泉回遊式庭園 | 11月中旬～12月上旬 |
| **常寂光寺** | 小眾賞楓祕境、竹林襯託 | 11月中旬 |
| **寶嚴院** | 賞楓季特別開放 | 11月中旬～12月上旬 |
| **大河內山莊** | 庭園眺望嵐山、可體驗抹茶 | 11月中旬 |
| **渡月橋** | 嵐山地標，楓紅與橋影倒映 | 11月下旬 |
| **竹林小徑** | 白天綠竹，夜晚點燈後氛圍絕佳 | 10月月燈路期間 |

### 嵐山小火車賞楓

- **行駛期間**：全年（冬季12/1-2/28停駛）
- **賞楓季**：10月中旬-11月中旬為最佳時段
- **建議**：去程坐右側（風景佳），回程坐左側
- **票價**：全票¥880

### 建議行程（嵐山賞楓夜遊）

```
白天
嵐山小火車（龜岡→嵐山）
天龍寺賞楓
竹林小徑散步
渡月橋拍照

傍晚
嵐山月燈路點燈（18:00開始）
野宮神社周邊
嵐山商圈購物/晚餐
```

## 🌉 東福寺・通天橋賞楓（京都）

### 景點地位

東福寺連續多年蟬聯京都賞楓人氣第一名，種植約2000多棵楓樹，每到秋季山谷間染成一片火海。

### 賞楓亮點

- **通天橋**：連接本堂與開山堂的廊橋，是最佳賞楓觀景點
- 從橋上俯瞰**洗玉澗峽谷**，整片紅葉宛如火焰燃燒
- 夾在通天橋與臥雲橋之間的山谷，是拍攝紅葉火海的最佳角度

### 票價資訊

| 時期 | 成人 | 中小學生 |
|------|------|----------|
| 非賞楓季 | ¥600 | ¥300 |
| 賞楓季（2025年為11/15-12/7） | ¥1,000 | ¥500 |

> ⚠️ 賞楓季人潮眾多，建議一大早剛開門（8:00）就到，避免排隊

### 人潮攻略

1. **早鳥策略**：開門後立即進園，趁人少時先到通天橋
2. **拍攝時機**：通天橋上禁止拍照，需在橋前後的指定區域拍攝
3. **平日優先**：週末人潮最為壅擠，建議平日到訪

### 賞楓期預測

根據2025-2026年資料，東福寺最佳賞楓期為**11月中旬至12月上旬**，2026年因氣候預測較晚，見頃時間可能推遲。

### 順遊建議

東福寺位於京都東南部，賞楓季時可與以下景點結合：

```
Day 5 或 Day 6
東福寺（上午）
    ↓（步行10分鐘）
伏見稻荷大社（下午）
    ↓（晚上）
嵐山月燈路（10月限定）
```

## 🏯 大阪城公園秋季銀杏（大阪）

### 賞銀杏黃金時段

大阪城公園的銀杏見頃時間為**11月下旬至12月上旬**，但10月也有銀杏大道可賞。

### 秋季亮點

| 景點 | 賞期 |
|------|------|
| 天守閣前大銀杏樹（樹齡約300年） | 11月下旬～12月上旬 |
| 銀杏大道（桃園旁一段） | 11月下旬～12月上旬 |
| 西之丸庭園 | 11月中旬～12月上旬 |

### 秋季活動

- **大阪城秋祭（大阪城秋祭）**：通常在10月-11月舉辦
- 園內有**丹桂、銀桂、十月櫻、銀杏、雞爪槭**等植物接力變色

### 夜間活動

- 天守閣有時會舉辦特別夜間點燈活動（視年度安排）
- 西之丸庭園在賞楓季可能有夜間特別公開

### 建議停留

| 項目 | 說明 |
|------|------|
| 賞銀杏/賞楓 | 1.5-2小時 |
| 搭配天守閣 | 再加1.5小時 |

### 秋季穿搭建議

10月的大阪城公園日夜溫差大，建議洋蔥式穿搭：

- 白天：長袖薄衫 + 輕薄外套
- 傍晚後：加件毛衣或羽絨背心
- 攜帶雨具（10月為雨季）

## 🌃 道頓堀運河夜遊（大阪）

### 道頓堀夜景散步路線

道頓堀是大阪最具代表性的繁華街區，夜晚霓虹燈璀璨，是打卡與美食的最佳時段。

### 經典打卡點

| 打卡點 | 說明 |
|--------|------|
| **戎橋 × 固力果跑跑人** | 大阪第一名片，沒打卡等於沒來過 |
| **道頓堀川畔** | 運河倒影與五光十色霓虹 |
| **太左衛門橋** | 夜景浪漫，運河倒影絕佳拍攝點 |
| **蟹道樂巨大螃蟹招牌** | 道頓堀地標之一 |
| **食倒太郎** | 逗趣人偶，可拍照留念 |

### 固力果跑跑人拍攝攻略

| 項目 | 建議 |
|------|------|
| 拍攝位置 | 站在戎橋上或河對岸行人區 |
| 拍攝時間 | **晚上**為佳，燈光更繽紛醒目 |
| 創意拍法 | 模仿跑跑人的姿勢合照 |
| 隱藏版 | 固力果藥妝店旁邊可拍到全景 |

### 水上觀光船

| 項目 | 說明 |
|------|------|
| 票價 | 成人¥2,000 / 學生¥1,000 / 小學生¥500 |
| 營業時間 | 11:00-21:00（每30分鐘一班） |
| 特惠 | 持大阪周遊卡免費搭乘 |
| 建議 | 選傍晚或晚上，欣賞霓虹燈倒影 |

### 道頓堀美食推薦（夜晚）

| 美食 | 店家 | 建議品嘗 |
|------|------|----------|
| 章魚燒 | たこ家道頓堀くくる本店 | 體驗外酥內嫩漉出高湯的特色 |
| 串炸 | 串炸Daruma | 蘸醬一次，限定喫法 |
| 拉麵 | 金龍拉麵 | 24小時營業，深夜食堂 |

### 散步路線建議

```
難波站
    ↓
戎橋（固力果跑跑人）
    ↓
道頓堀川畔（拍照欣賞夜景）
    ↓
太左衛門橋（倒影最佳拍攝點）
    ↓
法善寺橫丁（石疊小路、夫婦善哉）
    ↓
心齋橋商店街（順購物）
```

### 備註

- 道頓堀為24小時開放（店鋪各異）
- 秋季夜晚涼爽，建議帶薄外套
- 人潮眾多時請注意隨身財物

## 🍁 秋季賞楓延伸行程（10月）

### 箕面公園＋勝尾寺一日遊

這條路線可串聯大阪最重要的賞楓祕境：

```
上午
大阪城公園（賞銀杏/楓葉）
    ↓
移動至箕面（約40分鐘）

午餐
箕面站周邊（炸楓葉小喫）

下午
箕面公園（瀧道→瀑布）40分鐘步行
    ↓
勝尾寺（賞楓+達摩御守）
    ↓
回程
```

### 交通方式

| 區間 | 交通 |
|------|------|
| 大阪→箕面 | JR大阪環狀線至「石橋阪大前」，換乘阪急箕面線至「箕面」 |
| 箕面→勝尾寺 | 賞楓季有直達巴士（約35分鐘，來回票¥1,800） |

### 秋季限定活動對照表

| 活動名稱 | 舉辦時間 | 特色 |
|----------|----------|------|
| 嵐山月燈路 | 每年10月 | 竹林點燈、渡月橋夜景 |
| 箕面公園楓葉節 | 11月 | 瀑布周邊楓紅、夜間點燈 |
| 高臺寺夜間點燈 | 10月下旬-12月 | 光雕投影+庭園紅葉 |
| 永觀堂夜楓 | 11月 | 京都人氣最高的夜楓景點 |
| 清水寺夜楓 | 11月下旬-12月上旬 | 清水舞臺燈光秀 |
