# 天氣與穿著（10月）

## 氣溫參考

| 時期 | 平均高溫 | 平均低溫 | 建議穿著 |
|------|----------|----------|----------|
| 10月上旬 | 24°C | 16°C | 長袖薄衫 + 薄外套 |
| 10月中旬 | 22°C | 14°C | 長袖 + 輕薄羽絨/防風外套 |
| 10月下旬 | 19°C | 12°C | 毛衣 + 厚外套 + 圍巾 |

---

## 穿搭建議

### 上衣
- 長袖薄雪紡紗、針織毛背心、長袖襯衫

### 下著
- 長褲、褲襪、裙子（可搭配褲襪）

### 外套
- 薄外套、輕羽絨（建議防風）

### 鞋子
- 舒適步行鞋、包鞋、短靴

### 配件
- 圍巾、帽子（早晚溫差大可保暖）

### 備用品
- 發熱衣（日本10月為乾冷，建議帶一件備用）

---

## 天氣提醒

| 項目 | 說明 |
|------|------|
| 日夜溫差 | 可達10°C，洋蔥式穿搭必備 |
| 降雨 | 10月為日本的雨季，建議攜帶摺疊傘 |
| 濕度 | 相對乾燥，護手霜、護脣膏建議攜帶 |
