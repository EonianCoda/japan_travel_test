## 四種關西JR Pass比較

### 1. 關西地區鐵路周遊券

| 項目 | 內容 |
|------|------|
| 天數 | 1-4天彈性選擇 |
| 適用範圍 | 關西機場、大阪、京都、神戶、奈良 |
| 新幹線 | 不可搭乘 |
| 票價 | 一日券 ¥2,800（兒童 ¥1,400）至四日券 ¥7,000（兒童 ¥3,500） |
