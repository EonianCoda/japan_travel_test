> 來源：https://osaka.letsgojp.com/archives/858802/
> 擷取日期：2026-05-24

## 門票票價（2026年4月後）

| 票種 | 票價 |
|------|------|
| 高中生以上 | ¥1,000 |
| 中小學生 | ¥500 |
| 小學生以下 | 免費 |
| 身心障礙者等 | ¥100 |

- 一般參觀以現場入場為主
- 春季或秋季特別參觀活動期間可能調整，需依寺方公告

## 開放時間

| 季節 | 開放時間 |
|------|----------|
| 3月-11月 | 8:30-17:00 |
| 12月-2月 | 9:00-16:30 |

- 全年無休息日
- 櫻花季、紅葉季與日本長假期間建議出發前確認官網

## 建議停留時間

- 基本參觀：40分鐘-1小時
- 深度遊覽：1-1.5小時
- 延伸哲學之道散步至南禪寺：半天

## 交通方式

| 出發地 | 交通方式 | 時間 |
|--------|----------|------|
| 京都站 | 地下鐵烏丸線至「今出川站」→ 公車至「銀閣寺道」 | 約45分鐘 |
| 出町柳站 | 公車至「銀閣寺道」 | 約15-20分鐘 |
| 祇園四條 | 京阪電車至「出町柳」→ 公車至「銀閣寺道」 | 約30分鐘 |
| 金閣寺 | 京都市巴士204號 | 約35-45分鐘 |

## 境內必看

- **銀閣（觀音殿）**：國寶，與金閣寺舍利殿、西本願寺飛雲閣並列「京之三閣」
- 兩層空間命名為「心空殿」與「潮音閣」
